EXPERIENCE LAB - GEMINI AI

1. Tao Gemini API key trong Google AI Studio.
2. Deploy thu muc nay len Vercel (co the Import truc tiep GitHub repository).
3. Trong Vercel > Project > Settings > Environment Variables, tao:
   GEMINI_API_KEY = API key cua ban
4. Redeploy.

Khach truy cap website KHONG can dang nhap Gemini/AI.
API key chi nam o bien moi truong tren server, khong nam trong HTML/JS cong khai.

Luu y: GitHub Pages chi host file tinh va khong chay thu muc /api. Neu giu GitHub Pages, can host backend o noi khac va doi endpoint trong ai-client.js. Cach don gian nhat la deploy cung repository nay tren Vercel.
